# Организация записи на консультации

Учёт интервалов консультаций, участников и записей на эти интервалы.

## Запуск

python -m src.main

## Структура

- src/models.py  — доменные классы (Interval, Participant, Booking)
- src/storage.py — хранилище данных
- src/service.py — прикладные правила
- src/main.py    — консольный интерфейс
